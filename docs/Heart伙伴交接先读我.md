## 快速安装

先关闭并备份目标MaiBot。在解压包目录打开PowerShell，替换实际路径：

```powershell
python scripts/install_heart_plugins.py --target "D:\MaiBot"
python scripts/install_heart_plugins.py --target "D:\MaiBot" --apply
```

先执行第一行，检查成功后才执行第二行。安装器既部署插件也应用两份底层补丁；只复制plugins目录不够。已有配置保留，无法识别的代码改动会拒绝覆盖。不会自动启动QQ或调用模型。

## 包含/不包含

包含：可读源码、默认配置、两份底层补丁、安装器、离线测试、教程、虚构示例日志、许可证、SHA256文件校验表。

不包含：QQ/NapCat登录态、模型密钥、真实聊天/记忆数据库、当前心情、私人日志、Python虚拟环境、完整MaiBot或其他队友的定制。

AI心情默认关闭，朋友需自行开启。自定义区间、心情数值、自己的模型和QQ连接均不从原电脑迁移。
