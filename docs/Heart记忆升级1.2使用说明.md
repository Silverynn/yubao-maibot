# Heart 记忆升级 1.2.1：记住、候选、查看与忘记

Heart 继续使用 MaiBot 原生 A_memorix 作为唯一长期记忆库。原生系统负责提取、检索、存储、人物画像和删除；Heart 增加本人命令、候选审核、冲突确认、权限核对及易读日志。心情插件不受影响。

## QQ 指令

| 指令 | 使用范围 | 效果 |
|---|---|---|
| `/记住 我正在学习 Python` | 私聊或群聊 | 为发言者本人请求写入长期人物事实；冲突时先私聊核实 |
| `/我的记忆`、`/我的记忆 2` | 仅私聊 | 看本人的有效长期人物事实，每页20条 |
| `/候选记忆` | 仅私聊 | 看 AI 自动筛选、尚未写入的候选 |
| `/确认候选记忆 3`、`/忽略候选记忆 3` | 仅私聊 | 确认后交给原生存储（仍检查冲突），或忽略 |
| `/忘记 Python` | 仅私聊 | 按关键词找本人长期记忆；恰好一条时提出删除，但暂不执行 |
| `/确认忘记 4`、`/取消忘记 4` | 仅私聊 | 10分钟内确认才调用原生精确删除并复核；编号以实际回复为准 |
| `把我觉得 C++ 很难的记忆忘掉` | 仅私聊 | 自然语言定位本人旧事实；先列出目标，**此时不删除** |
| `确认忘记`、`取消忘记` | 仅私聊 | 只有当前恰好一条待确认请求时可不带编号处理；有多条时仍需编号 |
| `/确认记忆更新 5`、`/取消记忆更新 5` | 仅私聊 | 新旧事实冲突时，按原流程确认替换或保留 |

`/忘记` 若命中多条，机器人要求缩小关键词，不会擅自删除。群聊无法查看或删除个人记忆。`/记住` 把内容作为发言者的“本人自述”保存，不适合拿来保存第三人的未经证实信息。原生事实列表上限1000条；超过时须人工核查，不能保证列表完整。

普通聊天提出忘记请求时，插件先拦截这句消息，用现有 `utils` 模型判断是否真的在要求删除本人记忆、定位旧事实。模型**只选编号，没有删除权限**；置信度低于85%、目标含糊、模型超时或事实过多时都不删除，并提示改用精确指令。定位成功会列出拟删除内容；本人在10分钟内确认后，才调用 MaiBot 原生删除服务，再重新读取事实核对。像 `愁无寐觉得C++算法很难` 和 `愁无寐觉得 C++ 算法很难` 这种仅空格不同的重复事实，会一起列出供核对、一起删除。若机器人只是口头说“忘了”，却没有出现**待确认目标**和**删除成功并复核**，就不算真的删除；不要把闲聊回复当作后台结果。

普通聊天时，MaiBot 原生 AI 先判断是否有值得长期保存的本人事实。默认设置下自动提取的内容**先进入候选区，不会悄悄进入长期记忆**；本人私聊确认后才写入。如果将 `auto_candidates.enabled` 关掉，原生自动提取恢复直接写入，但仍经过已启用的冲突检查。MaiBot 的原生人物事实自动提取功能本身必须打开，否则 Heart 没有候选来源。后台提取可能比回复稍晚。

自动候选保存原话证据编号；无法核实原发言者时既不进候选，也不写长期记忆。每人候选达到上限会停止新增。确认候选仍会经过冲突关卡，因此遇到矛盾时可能先后出现“确认候选”和“确认记忆更新”；这是两个不同决定。

## 在 WebUI 修改 AI 的筛选提示词

打开 MaiBot WebUI → 插件管理 → **Heart 记忆与对话记录** → “自动候选记忆”：

- `enabled`：开 = 自动提取先入候选；关 = 原生直接写入。
- `max_pending_per_person`：每人的候选上限。
- `selection_guidance`：追加给原生 AI 提取器的筛选原则。例：`优先记长期学习目标和稳定偏好；一时情绪和普通寒暄不记。`

这段提示词辅助筛选，不保证模型每次判断正确；原生“必须有用户原话证据、必须属于本人”的规则继续保留。不要在提示词中写密钥或私人资料。修改后建议重启 MaiBot，用虚构测试消息查看候选和日志。

## 日志与忘记的边界

每天的可读日志在 `目标MaiBot/data/heart_observation/logs/YYYY-MM-DD.txt`，每条空一行。包括对话、检索候选、提供给模型的记忆参考、候选新增/确认/忽略、手动写入、冲突确认和忘记结果。长内部编号与完整 JSON 不铺满文本日志。`检索候选`不等于模型最终采用；`进入候选`不等于已写长期记忆；必须以原生服务报告为准。

确认忘记会让原生系统按精确段落编号删除，并重新读取本人有效事实复核。自然语言定位、待确认目标、取消/超时、删除与复核也分别进入当日日志。原生系统可能仍保留可恢复的删除快照；Heart 审计日志也保留历史原文。因此不能承诺“所有备份与日志中物理意义上完全擦除”。彻底删除隐私信息还需单独审查原生回收、备份和本地审计副本。

## 建议验收

1. 私聊 `/记住 我在学习 Python`，收到存储确认后用 `/我的记忆` 查到；检查“手动记忆请求”和“记忆操作结果”日志。
2. 普通聊天说一个新的长期偏好，稍等后用 `/候选记忆` 查到；确认前 `/我的记忆` 不应出现。再用 `/确认候选记忆 编号` 并复查。
3. 用 `/忘记 Python` 提案后先取消，确认旧记忆还在；重新提案后确认删除，确认从 `/我的记忆` 消失、日志记录删除与复核。
4. 提出与已有偏好冲突的新事实，验证原有的“旧/新”私聊确认仍可取消或更新。
5. 私聊说 `把我觉得 C++ 很难的记忆忘掉`，先核对机器人列出的目标；发送 `取消忘记` 验证不删，再重新提案并发送 `确认忘记`，随后用 `/我的记忆` 检查相关事实已消失。若列错目标，不要确认。

上述在线验收会向 QQ 发送消息、可能调用现有模型并修改测试记忆。请使用虚构内容并取得参与者同意；离线自动测试不连 QQ 或付费模型。
