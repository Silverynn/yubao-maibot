# Heart 实时插件 0.2.1：日志精简与连接恢复增量

这是 2026-10-09 Heart 完整交付之后的 **11 文件增量**。基于 MaiBot 1.2.5 / SDK 2.8.1、Open-LLM-VTuber 1.2.1 的已有实时接缝。不是独立安装包，也不把个人 Live2D 的完整 Lv4.5 自动移植到 StoryRoom。

先读 [给伙伴 GPT 的安装步骤](docs/给伙伴GPT的安装说明.md)，再看 [与上次交付的区别](docs/与上次交付的区别.md) 和 [功能及验收](docs/功能与验收.md)。代码版本仍是 0.2.1，以本包 release 名与 SHA256 区分更新，不能只看版本号判断是否已安装。

新增内容：一次输入一个日志区块、工具开始/结果与草稿采用/丢弃可读记录、控制台摘要、重复转写不延后草稿、查询稳定和去重、录音结束通知、失联重绑、新旧连接音频隔离。QQ处理、StoryRoom、模型任务选择及伙伴的声线/形象保持现状。

安装器默认只读比较，实际写入只允许同时应用 shared/realtime/vt 三部分。已有文件仅在基线或最终指纹匹配时处理；伙伴自改一律停止整批写入并要求三方合并。支持检测重命名的实时插件目录，拒绝重复插件实例。应用前需停机、审查、检查已有宿主/前端接缝；备份和失败回退覆盖两端。

**不要整体复制 `maibot` 或 `vt` 目录。** `INSTALL_MANIFEST.json` 只有 11 个部署目标；其他源码用于离线测试和比较，不是需要重新部署的主程序或声线。

验证：本交付目录 104 项 Python 离线回归、26 项前端断言，包含中文目录、重命名插件、半套安装拒绝、自改冲突、配置/数据保留、双端备份和写失败回退。已有两端接缝的本机只读检查通过。此前同版代码用真实 ASR、工具和两次回复模型调用验证了提前启动，证据摘要见 `VALIDATION.json`；本次封装没有再调用收费模型、发送QQ消息或安装到伙伴电脑。

没有配置、密钥、实际日志/聊天/记忆、模型/声线/Live2D资源或 Core 二进制。既有 Oct9 包已经去掉的固定角色名、固定本地声线健康探针和个人演示音频路径不会被本机版本带回来。

许可证分别保留于 `licenses/` 与插件 `LICENSE`。宿主参考源码沿用 MaiBot GPL-3.0；VT 接缝对应 Open-LLM-VTuber 的许可证。不同来源不统一改授权。
