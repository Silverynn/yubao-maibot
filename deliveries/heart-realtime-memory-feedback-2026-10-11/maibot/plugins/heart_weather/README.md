# Heart 天气查询

为当前 MaiBot 提供真实天气工具，不修改原生记忆、心情或回复策略。

- 管理后台 → 插件配置 → **Heart 天气查询**：启用开关、国家、超时、缓存均可调整。
- 自然语言：“查询今天西安天气”。原生规划器发现并选择 `query_weather`。
- 直接命令：`/天气 西安`，查询今天预报，不经过模型工具选择。
- 不明确的地点、网络错误、超时如实返回，不生成猜测天气。
- 数据来源：[Open-Meteo](https://open-meteo.com/en/docs)。只发送城市/坐标，不读取私人聊天历史。免费接口用于非商业学习演示，商业使用须另行检查条款。

工具参数：`city` 为城市名；`days` 取0～7（0当前模型估计值、1今天、2含明天）；可选 `purpose` 为一句公开的调用理由。

## 配套审计

每次天气查询会在 MaiBot 普通运行日志中记录成功/失败、耗时、来源和返回的天气内容。若要将它显示在已有 Heart 消息卡片中，还需要目标实例已经具有宿主 `heart_tool_observer.py` 接口和共享 `heart_shared/tool_audit.py` 模块。

本次交付**不携带这些共享模块或原生补丁，不覆盖任何其他插件**。自然语言天气的共享卡片由已接入的宿主统一记录；直接天气命令尝试使用已有共享接口。若接口不存在或写入失败，会在普通运行日志提示，但天气查询和命令回复继续正常返回，不重复查询。通用的所有工具日志不是这个独立天气插件能单独保证的。

共享卡片总开关沿用已有日志设置；天气插件普通运行日志跟随 MaiBot 日志设置。可选 `purpose` 参数仅提供一句公开调用理由，不记录模型隐藏推理。工具成功返回不等于最终回复采用该结果。

本地日志含私人对话，不应把 `data/` 或真实运行日志上传到公开仓库。无需新增模型密钥；依赖当前宿主已有的 `httpx` 和兼容 SDK。

## 给同伴及其 AI 助手的安装步骤

1. 找到**真正运行的 MaiBot 目录**（包含主程序、`src/`、`plugins/`、虚拟环境），先关闭 MaiBot。仓库外层项目目录不一定就是运行目录。
2. 只把本目录复制为运行目录下的 `plugins/heart_weather/`。如果目标已有同名天气插件，先备份并比较；**不要覆盖它已有的 `config.toml`**。
3. 不执行旧交付包的批量安装器，不复制任何心情/记忆/跑团目录，不覆盖 `heart_shared/`、`src/`、模型配置、Live2D、语音、数据库和密钥。不要为装天气顺便升级其他插件。
4. 确认宿主版本在1.2.4～1.2.x、SDK在2.8～2.x；目标Python环境应可导入 `httpx` 和 `maibot_sdk`。若有版本差异先核对，不擅自升级整个宿主。
5. 重启 MaiBot，在插件页确认 **Heart 天气查询 1.0.1** 已加载。配置页默认中国、网络最长12秒、短时缓存300秒，无需天气API密钥。
6. 先发 `/天气 西安`，再试“查一下今天西安天气”。前者验证真实查询，后者还依赖原生规划器发现并选择天气工具。
7. 若查询成功但没有共享消息卡片，只检查目标是否已有上面提到的可选日志接口；不要恢复旧交付包以补接口，也不要修改升级后的插件。是否新增接口需另行讨论。

只取这个插件目录，不要切换/覆盖整个仓库来安装，以免碰到同伴本地已经修改的其他文件。
