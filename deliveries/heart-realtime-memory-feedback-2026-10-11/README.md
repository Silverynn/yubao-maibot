# 实时记忆反馈与提前生成原因日志补丁

用户同时问“还记得我的项目吗”和天气时，原有模型虽收到空检索结果，却可能只回复天气。本增量要求同时回应明确问题，历史检索无命中时简短说明未找到记录；查询失败不冒充无命中。

正式回复与提前草稿共用证据提示；在实际构建模型上下文时记录命中数、来源状态和天气结果是否可用。它不是模型一定遵守提示的证明。提前生成仍由程序规则门禁决定，模型仅在获准后写草稿。日志记录具体原因码、命中的词、文字长度、稳定阈值与查询等待状态。

## 依赖与范围

先安装 [PR #5](https://github.com/Silverynn/yubao-maibot/pull/5) 的 `heart-realtime-0.2.1-log-reconnect-2026-10-10` 包；本包不能单独替代基础宿主接缝。附带必要的前置修复：分开提取同一句中的记忆和天气查询，“提醒”等写操作不再拦住只读查询；天气支持父城市/区县和下午逐小时预报；日志按已明确绑定的访客身份归组，不生成无输入空文件。

安装清单只含 15 个 MaiBot 源码/插件文档目标。`maibot/` 和 `vt/` 里的其他公开代码用于隔离测试，安装器不部署它们。原有 VT 音色、模型、运行配置、密钥、消息/记忆库均不在安装范围。若 VT 每次使用新访客身份，这个包不会擅自把不同访客的记忆或日志合并；稳定浏览器身份桥需另外适配。

## 验证与安装

在本目录执行（Python 3.12；使用已安装依赖的 MaiBot 环境）：

```powershell
python -B tools/verify_delivery.py
python -B tests/run_offline.py
python -B tests/test_memory_feedback.py
python -B tests/test_installer.py
python -B tools/install_delivery.py --maibot-root "你的 MaiBot 目录"
```

默认只读。检查无冲突、停止 MaiBot 与守护程序后：

```powershell
python -B tools/install_delivery.py --maibot-root "你的 MaiBot 目录" --apply --stopped
```

未知自改版整批拒绝写入；根据 `baseline/` 和 `patches/` 三方合并，不能整目录覆盖。备份和安装收据在目标 `data/heart_install_backups/`。天气插件为 `heart.weather`，已有同 ID 插件沿用其目录，多个同 ID 会拒绝；从未安装的实例安装后应在插件管理确认启用状态。天气依赖已有 httpx，无额外模型密钥。

安装后重启 MaiBot，并刷新 VT 页面重新绑定实时插件。实际语音效果需要重新对话验证；离线测试不调用真实模型、不发 QQ 消息。

## 日志示例（虚构输入）

输入：“你还记得我做机器人吗？查一下西安市长安区下午的天气，下雨请提醒我带伞。”

- 提前生成：未启动，命中“提醒”，可能涉及需确认的操作，等待正式转写；只读查询仍可继续。判断来源：程序规则；原因码：confirmation_required。
- 回复模型查询依据：记忆检索已完成：无命中；原生本人记忆命中 0 项；本地事实命中 0 项；天气查询已完成。

日志路径是目标 MaiBot 的 `data/heart_observation/logs/Live2D/`。旧记录不补写虚假的上下文传递事件。本包不公开真实日志、访客 ID、聊天记录或密钥；新增观测仅记录可审计的程序状态，不记录模型隐藏推理。

## 验收边界与回退

本机验证 MaiBot 1.2.4 / SDK 2.8.1；PR #5 的宿主检查以其自身版本要求为准，本增量不升级或伪改主程序版本。107 项离线行为测试通过，其中新增 13 项；另有 6 项安装器测试；真实模型的自然语言措辞不保证每次一致。

回退前停止服务与守护程序，按安装收据恢复修改前源码；只移除收据标记为新增、且内容仍与安装指纹一致的文件。不要删除 `data/`、配置或数据库。保留原有基础包的许可证与作者信息；混合仓库不会因本增量获得统一的新授权。
