# Heart 记忆插件（管理与日志）

这是已安装的heart.memory-audit，原名“Heart 记忆与对话记录”。插件ID保持不变，原有配置和记忆继续使用。它增强MaiBot内置记忆流，没有另外建立一套替代原生记忆的数据库。

## 选择聊天摘要使用的模型

[打开记忆流模型配置](/config/model?field=model_task_config.memory&tab=tasks)

在“记忆流模型 (memory)”中，从已有模型中选择，并确认保存成功。它用于聊天摘要等采用memory任务的调用，不会自动改变回复、规划、心情、事实提取或冲突判断的模型。原生总结选择器为auto时优先使用memory；若管理员配置过其他明确选择器，则以该选择器为准。

“账号余额不足 / HTTP 402”表示被选模型对应服务商账户余额不足；显示入口并不会充值或保证模型可用。建议选择你确认有额度的文本模型，不要选择嵌入模型。修改后从原桌面入口正常重启，不要同时启动第二套机器人。

## 本插件负责哪些功能

- 本人主动记住、候选审核、新旧事实冲突确认和同义重复检查。
- 忘记和更新实际衔接原生记忆，并保留操作记录。
- 群回忆按来源范围查询，保留群/私聊隔离。
- 记录收到对话、记忆参考、判断、操作结果、回复与发送等观察事件。

人物事实提取、语义去重等调用目前有自己的任务配置，不能把memory这一个选项理解成所有记忆相关调用的总开关。向量模型也单独配置，直接换向量模型可能造成维度不一致。

## 在哪里找到本插件

这是本机已安装插件，请在“插件配置/已安装插件”中搜索“记忆”或heart.memory-audit；插件市场主要展示已发布条目，不保证展示本地插件。确认关闭“仅看有更新”等筛选，再刷新页面。插件存在、已启用、已加载是三种不同状态，机器人关闭时不应把列表里的“未启动”当成加载成功。

## 独立选择记忆查重模型

[打开记忆查重／冲突判断模型](/config/model?field=model_task_config.heart_memory_dedup&tab=tasks)

此项同时用于人物事实的同义去重／冲突检查，以及聊天摘要写入前的语义去重。先在“模型列表”添加文本模型，再在此任务勾选，确认保存成功。列表留空时继用utils全部原设置。完全相同的正文无需调用模型。此项不改变记忆流摘要生成(memory)、人物事实提取、自然语言忘记定位或嵌入模型。

摘要判断仍使用插件的输出预算和总等待时限，人物事实判断使用此任务输出预算，并受插件等待时限约束；不会修改旧记忆或关闭本人确认。原生模型日志按heart.memory_conflict、heart.summary_semantic记录实际模型与用量。
