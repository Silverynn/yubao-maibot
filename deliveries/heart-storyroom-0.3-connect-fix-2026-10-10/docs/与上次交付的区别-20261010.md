# 对比上次 StoryRoom 0.2：本次 0.3 的更新

上次跑团交付是伙伴仓库 PR #5，提交 `7c405d0579cf7bb7972e1e34c36a74935440dfbf`。本次新增独立0.3交付目录，保留0.2包与10月9日日常插件包。

| 方面 | 上次0.2 | 本次0.3 |
|---|---|---|
| 世界线 | 主要使用固定示例 | 网页编辑世界、阶段、分支、结局，JSON导入导出；模板与当前房间分开 |
| 发言 | 主持人点名任务 | 介绍结束后轮流自主讨论、提问、行动；等待GM回答或裁决后继续 |
| 发言控制 | 取消和版本限制 | 主持人讲话锁、网页朗读租约、发言次数限制、失联暂停 |
| 记忆 | 本角色已确认经历 | 公共故事、同伴经历、其他玩家资料，修改/撤销；与日常聊天隔离 |
| 旁听 | 领取任务时读取上下文 | 独立异步任务同步公共事件，旁听本身不调用模型 |
| 卡住恢复 | 生成租约和重传 | 现场变更取消旧任务，离线排队超时，过期任务有限重试 |
| 升级 | 初装保护 | 校验0.2发布源码升级，自改停止，保留配置/Git/数据并备份 |
| 启动 | 重复启动仍按旧协议判断 | 修复运行中0.3误报端口占用，协议不匹配明确提示正常停机 |
| 安装文档 | 0.2点名流程 | 0.3升级、共同HTTPS地址、独立PC密钥、主机模型资源与GPT指南 |

没有MaiBot主程序改动，不覆盖伙伴原语音包、模型、日常心情/记忆/实时插件。平台和两侧PC均需0.3；旧库先一致备份再增量迁移。自改源码需三方合并。运行配置、日志、密钥、模型/Core/权重不上传。

共同地址尚需运营方部署HTTPS；平台主机准备两套授权Live2D，浏览器自动加载，PC插件不自动上传伙伴模型。定制声线、真实公网、真实模型与真人语音仍需两人联调。详见 [GPT安装指南](给同伴AI助手的安装说明-20261010.md) 和 [0.3分步教程](StoryRoom-0.3-使用教程与已知缺陷-20261010.md)。

## 与10月9日交付的区别

上次交付为Heart实时链路、QQ语音观测、回复显示修复、管理入口、心情/记忆独立选模等。此次另加独立的StoryRoom源码与跑团PC插件，旧交付目录和ZIP不覆盖。

| 方面 | 上次包 | 本次新增 |
|---|---|---|
| 主要目的 | 日常角色、QQ、VT实时对话 | 有限世界线中的双机器人跑团 |
| 多方连接 | 本机VT绑定MaiBot | 两台MaiBot主动访问一个HTTPS房间 |
| 角色行动 | 直接日常回复及工具链 | 先提案，再检定，再GM裁决 |
| 状态与记忆 | 日常心情/长期记忆 | 独立房间角色卡、心情、信任、已确认经历 |
| 故事边界 | 没有正式有限跑团阶段 | 锁定剧本副本、限定跳转与3个结局 |
| 形象 | 原VT界面 | 双Live2D共享舞台，使用各自映射 |
| 声音开关 | 原VT声音及实时开关 | 每角色本浏览器朗读、单交谈角色连续收音 |
| 审计 | 原实时/心情/记忆日志 | 开关、上下文、输出、投骰、裁决、状态变化及语音回执 |
| 宿主改动 | 配套宿主接缝 | 本次不再修改MaiBot主程序 |

现有心情、记忆、原VT实时、QQ ASR、伙伴语音包与模型预算都保留。本次不包含此前已回退的省额度修改，也不迁移QQ聊天数据库。PC插件只申请`llm.generate`。

StoryRoom的连续语音模式不等于原VT实时插件全部移植。原Lv4.5提前生成、边听边查、证据纠正继续留在原链路；StoryRoom暂未接入。伙伴自己的定制声线也未自动接入共享舞台，当前是系统本地朗读。

主要兼容修复：Windows静态JS MIME、模型动态表情名/编号、已有表情与忙碌动作回执、旧库安全迁移、断线结果重发、绑定变化隔离、现场变化取消、浏览器过期识别丢弃、默认关闭安装与已有目录保护。

安装与逐步验收请按`给同伴AI助手的安装说明-20261010.md`和`伙伴使用与验收教程-20261010.md`。没有真实公网或伙伴电脑验收，不应自动开启收费PC或替换已有语音包。
