# 给伙伴GPT：修复跑团插件加载失败

任务：在伙伴实际运行的MaiBot中修复Heart跑团PC连接。保持现有玩家密钥、模型选择、配置、插件数据、QQ功能、个人Live2D与语音包。以下内容是安装操作说明，请按伙伴的授权执行，不自行发送密钥或改动MaiBot主程序。

## 1. 使用正确的新包

下载 `deliveries/heart-storyroom-0.3-connect-fix-2026-10-10.zip`，不要再使用旧0.3 ZIP。解压后阅读本操作单和总安装指南。找到实际MaiBot根目录和它自己的Python。只作为玩家的一方不用启动StoryRoom、下载主机模型或安装cloudflared。

```powershell
$roomDir = 'D:\解压后的新交付包'
$botDir = 'D:\实际运行的MaiBot'
$botPython = Join-Path $botDir '.venv\Scripts\python.exe'
& $botPython -X utf8 -B "$roomDir\scripts\verify_package.py"
& $botPython -X utf8 -B "$roomDir\scripts\check_compat.py" --maibot-root $botDir
```

Python3.12 / MaiBot1.2.5 / SDK2.8.1为已验证组合；其他版本要先检查原生校验器和SDK能力参数，不能假称全兼容。

## 2. 备份并修复插件

旧清单少了 `author.url`、`urls`、`i18n`，导致加载失败。此时输入正确PC密钥也不会联网，不要轮换密钥或调整模型API账号。

先关闭“启用跑团连接”再正常停止MaiBot，或者在停机状态下仅将已有配置的connection.enabled设为false；配置内其他值保留。不要把交付包的config.example.toml覆盖到现有config.toml。

已经安装原始0.3或旧0.2，先预检再升级：

```powershell
& $botPython -X utf8 -B "$roomDir\scripts\update_pc.py" $botDir
& $botPython -X utf8 -B "$roomDir\scripts\update_pc.py" $botDir --apply
```

升级器接受原始0.3完整发布指纹、修复后0.3指纹、旧0.2发布指纹；会备份五份源码和配置，保留config.toml、Git、插件数据及其他插件。若发现伙伴自改，停止自动覆盖，做三方比较。当前PC逻辑与上次0.3相同，本次PC必需修复仅为清单。自改插件可以只在现有清单中补齐下面三项，保留它原有ID、版本、描述、依赖和能力声明：

```json
"author": {
  "name": "Heart project contributors",
  "url": "https://github.com/Silverynn/yubao-maibot"
},
"urls": {"repository": "https://github.com/Silverynn/yubao-maibot"},
"i18n": {"default_locale": "zh-CN", "supported_locales": ["zh-CN"]}
```

这是JSON字段片段，需合并进原对象，不能作为整个清单覆盖。没有_locales目录时不声明不存在的locales_path；当前中文UI不依赖语言资源目录。作者名字有自改时保留原值，只补URL。补完使用该MaiBot的真实ManifestValidator检查实际安装副本，不只检查交付源文件：

```powershell
Set-Location -LiteralPath $botDir
& $botPython -X utf8 -B -c "from pathlib import Path; from src.plugin_runtime.runner.manifest_validator import ManifestValidator; v=ManifestValidator(project_root=Path.cwd(),log_errors=False); p=v.load_from_plugin_path(Path('plugins/storyroom_pc')); print('加载清单通过' if p else v.errors); raise SystemExit(0 if p else 1)"
```

## 3. 重新连接鱼宝

正常启动MaiBot，管理页刷新后应看到Heart跑团PC连接加载成功。共享房间地址填主机当前提供的HTTPS根地址，不能填伙伴自己的127.0.0.1。玩家连接密钥填鱼宝角色的PC密钥，与故机密钥不同；不要填GM网页登录密钥、MaiBot管理密钥或模型API key。已有鱼宝密钥有效时继续使用，不重新生成。

保存并开启“启用跑团连接”。StoryRoom鱼宝卡片应变成“PC连接在线”；只打开网页或加载形象不会产生这个状态。插件日志应出现enabled=true、协议验证通过（0.3）、持续旁听。未开放讨论时旁听不调用模型。

## 4. 主机形象与名字的变化

主机已把故机绑定moonbell-20261003、鱼宝绑定伙伴交付的yubao-fullbody，并保留旧房间、ID、密钥和记忆。旧日志保留当时称呼，另有更名审计。新网页默认也使用这两个称呼与已安装形象，角色名称仍可在建房时编辑。

主机前端修复：优先选择真实鱼宝；同角色换模型会释放旧实例并重新执行表情。只需主机更新web/app.js、web/avatar-defaults.js、web/stage.js、web/index.html等对应差异，然后Ctrl+F5刷新。不要在伙伴PC安装器中修改远程房间数据库，也不要在本机创建另一个同名房间来替代共享房间。

如果需要在别的主机迁移旧房间模型或改名，应先一致备份数据库，定位明确房间与角色，在事务中只修改name/avatar并记录审计，核对其余列不变。不要按名字批量替换所有历史记录。
